# 恐怖豆包

一个无需安装、可直接在浏览器中运行的单人逃生小游戏。

## 开始游戏

1. 保持 `index.html`、`styles.css`、`game.js` 和 `assets` 文件夹在同一目录中。
2. 双击 `index.html`，或把它拖进浏览器。
3. 点击“进入房子”。

## 玩法

- `W / A / S / D`：移动
- 鼠标：转向（点击游戏画面可重新捕获鼠标）
- `Shift`：奔跑
- 手机和平板：使用画面底部的触屏按钮

在迷宫里找到发光的钥匙，钥匙会自动拾取。拿到钥匙后前往带有逃生灯和黄铜门锁的红色出口门，靠近后会自动解锁。豆包会持续寻找并追赶你；如果太久没有露面，她可能会在前方走廊突然出现。

靠近豆包时会循环播放她的追逐语音，距离越近声音越大。胜利和失败结算也有各自的豆包语音。

## 文件说明

- `index.html`：页面与游戏界面
- `styles.css`：视觉样式和移动端适配
- `game.js`：迷宫、追逐、钥匙、逃生及音效逻辑
- `assets/doubao.jpg`：追击及失败结算使用的恐怖豆包图片
- `assets/doubao-normal.png`：胜利结算使用的正常豆包图片
- `assets/audio/victory.mp3`：胜利结算语音
- `assets/audio/caught.mp3`：失败结算语音
- `assets/audio/nearby.mp3`：近距离循环追逐语音

游戏不依赖网络或第三方框架，图片和语音均保存在 `assets` 文件夹中。
