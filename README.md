# 恐怖少帅 · 小锦

一个无需安装、可直接在浏览器中运行的单人/联机恐怖逃生小游戏。

## 剧情

善良人格**小锦**和邪恶人格**少帅**本是一体。

多年前一场大火里，小锦的妹妹**小洛**被锁在铁笼中。他掰断了十根手指也打不开那扇锁。
小洛隔着栏杆对他说：**"哥哥，你要活下去。"**

小锦活了下来，但精神分裂成了两个人格：
- **小锦（逃离者）**：想活下去，想遵守承诺。铁笼是妹妹最后待过的地方。
- **少帅（追捕者）**：认为是自己害死了妹妹，想毁掉这个还在笑的自己。

**为什么少帅只能走逃离者走过的路？** 因为他是逃离者的影子——内疚只能沿着经历生长。

**为什么两个人格不能共存？** 因为一个要忘掉，一个要记住。同一具身体，只能活一个。

**墙上的幻象：**
- 对逃离者来说，墙上闪烁的是邪恶少帅——因为他最怕变成那个自己。
- 对少帅来说，墙上闪烁的是善良小锦——因为他最怕看见妹妹最后看着他时，那张还在笑的脸。

## 玩法

- 逃离者目标：找枪 → 找刀 → 靠近铁笼按 Q 插刀 → 撑过 30 秒 → 走进铁笼（获胜）
- 少帅目标：顺着逃离者走过的红色路径追上去，距离 < 0.5 格即判定抓住（获胜）
- 少帅只能踩逃离者走过的格子

## 操作

- `W / A / S / D`：移动
- 鼠标：转向 / 瞄准
- `Shift`：奔跑
- `左键`：开枪
- `F`：换弹
- `Q`：插刀（靠近铁笼时）
- `Tab`：展开/关闭地图

## 游戏模式

### 每日挑战

每天 00:00 自动刷新一个**全局唯一**的种子（基于日期 FNV-1a 哈希）。
- **难度 2 · 噩梦**：1 个少帅，无感知
- **难度 1 · 地狱**：2 个少帅

**逃脱成功**才会提交成绩，从进入游戏到钻进铁笼之间的时间**越短排名越高**。
每个难度各有一张前十排行榜。

### 自由对战

自定义种子（数字）或随机种子，可选 5 种难度。不计入排行榜。

### 联机模式

两人通过 6 位房间号联机，P2P WebRTC 直连。
